# Changelog

## 0.1.0 — Initial public repository bundle (2026-10-23)

- Exact Spatial V6 inference loader for exported quantized model weights.
- 495-byte compact `.msr` packing and integrity checks.
- Desktop Tkinter GUI and Python command-line file/folder inference.
- Model format documentation and optional full research trainer/audit scripts.
- Synthetic correctness tests, CPU CI for Windows/Linux, checkpoint parity checker and GitHub release packaging.

**Note:** The 495-byte V6 model is included. Its terms are separate from the software MIT license.
